MODERN ONLINE FOOD ORDERING SYSTEM
Technologies: HTML5, CSS3, JavaScript

HOW TO RUN
1. Extract the project ZIP.
2. Open index.html in Chrome, Edge, Firefox, or another modern browser.
3. Browse categories, search dishes, add items, and open the cart.
4. Adjust quantities and try the demo checkout.

FEATURES
- Responsive modern food ordering UI
- Food cards with categories, ratings, prices, and images
- Search menu items
- Add to cart and quantity controls
- Live cart count and subtotal
- Demo checkout (no payment integration)

NOTE
This is a front-end academic/demo project. Checkout is simulated. Online payment,
backend database, authentication, and real order delivery are not connected.
Internet is required for Google Fonts and remote food images.
